# SIPLY — Splash Screen Animation

A single-page interface experiment exploring staged brand reveal animations.

## Features

Expanding circle, background transition, logo color change, curved panel reveal and a Continue button that restarts the animation.

## Technology

HTML, CSS transitions and vanilla JavaScript.

## Getting started

```sh
git clone https://github.com/mefrinthearea/SIPLY.git
cd SIPLY
```

Open `siply/index.htm` in a browser. No package installation or build step is required. External fonts or icons may require an internet connection.

## Entry point

`siply/index.htm`

## Scope and limitations

The button reloads the demo rather than navigating to a real application. Reduced-motion support has not been implemented.

## Project status

Early learning project retained to document development progress. Source reviewed for documentation; runtime behavior has not been re-tested in this update.
